Proyectos

1. Auditoría Integral de Ciberseguridad – Clínica San Expedito

Tipo: Proyecto académico | Caso empresarial simulado.

Evaluación de controles de seguridad físicos, lógicos y administrativos de una institución de salud ficticia.

Actividades realizadas:

Elaboración de inventario de activos críticos.

Diseño de cuestionarios de control interno y guías de inspección.

Documentación de papeles de trabajo y hallazgos de auditoría.

Análisis de riesgos mediante metodología CCCER.

Elaboración de matriz de riesgos 5x5.

Desarrollo de recomendaciones de seguridad y continuidad operativa.

Marcos de referencia: ISO/IEC 27001, NIST Cybersecurity Framework, CIS Controls v8 y LFPDPPP.

Consultar proyecto y reporte

2. Pruebas de Penetración Web – DVWA

Tipo: Proyecto académico | Laboratorio controlado de TryHackMe.

Evaluación de seguridad sobre Damn Vulnerable Web Application (DVWA), utilizando el nivel de seguridad Low para identificar y documentar vulnerabilidades comunes en aplicaciones web.

Actividades realizadas:

Pruebas de fuerza bruta en mecanismos de autenticación.

Identificación y explotación controlada de SQL Injection y Blind SQL Injection.

Pruebas de Command Injection.

Identificación de vulnerabilidades XSS (DOM, Reflected y Stored).

Análisis de validaciones del lado del cliente y File Upload.

Documentación de evidencias, impacto y recomendaciones de mitigación.

Herramientas utilizadas: Hydra y SQLmap.

Resultados: 9 vulnerabilidades documentadas en el reporte: 3 críticas, 5 altas y 1 media.
